### Stage S05 — Agent State Machine (FSM)
- File: [`packages/core/src/state-machine.ts`](file:///e:/ZEN%27S%20WEAR/Harness%20Learning/PROJECTS/zenswear-harness/packages/core/src/state-machine.ts)
- State transitions: `IDLE` → `ROUTING` → `EXECUTING` → `WAITING_APPROVAL` → `IDLE` / `ERROR`.
- Safety Guardrails:
  1. Max 5 iterations per execution cycle.
  2. Repeated action fingerprint detection (prevents infinite loops).
  3. Token budget circuit breaker.
  4. Mutative action approval gate (`resolveApproval(approved, reason)`).
